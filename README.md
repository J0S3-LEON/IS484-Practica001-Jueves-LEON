## Instalación y Configuración (Para quienes descarguen el proyecto)
Dado que la carpeta del entorno virtual (`venv_practica/`) no se sube a GitHub gracias al archivo `.gitignore`, deberás crear tu propio entorno localmente tras clonar o descargar este repositorio:

1. Abre tu terminal (bash) en la carpeta del proyecto.
2. Crea el entorno virtual ejecutando:
   ```bash
   python -m venv venv_practica
   ```

3. Activa el entorno virtual:
   * **En Windows (Git Bash):** `source venv_practica/Scripts/activate`
   * **En Linux/Mac:** `source venv_practica/bin/activate`

4. *(Opcional)* Instala Jupyter si tu entorno base no lo tiene enlazado:
   ```bash
   pip install jupyter
   ```
